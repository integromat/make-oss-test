### Make Apps COntributing

To contribute apps you need to open pullrequest with responding changes. The PR is then reviewed by our Apps Experts and potentialy merged. Once changes are merged, new version of app is realased.

### Your own Apps pipeline
If you owning some Make app, you can build your automation using make-cli.

1. fork repo
2. set envs MAKE_API_TOKEN and MAKE_API_HOST
3. install dev dependencies
4. use make-cli clone
5. make changes
6. let pipeline to update your Make app
